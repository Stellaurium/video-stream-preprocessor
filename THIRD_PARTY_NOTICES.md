# Third-party components

This source repository uses separately licensed dependencies installed from requirements.txt. Virtual environments, executables, copied package notices and generated images are not distributed in Git.

- OpenCV / opencv-contrib-python: <https://github.com/opencv/opencv> and <https://github.com/opencv/opencv-python>
- NumPy: <https://numpy.org/>
- PyAV and its FFmpeg dependencies: <https://github.com/PyAV-Org/PyAV>
- Qt for Python / PySide6 / Shiboken6: <https://code.qt.io/cgit/pyside/pyside-setup.git/> and <https://www.qt.io/licensing/>
- FFmpeg command-line executable, supplied by the user: <https://ffmpeg.org/download.html>

Upstream license and third-party notice texts are provided with the installed distributions. If redistributing a binary environment or FFmpeg separately, retain the notices and meet the source obligations applicable to that chosen build. The source repository does not select a license for its owner's application code.

Microsoft YaHei is read from Windows system fonts; fonts are not redistributed. The calibration board is generated by this project's own calibration code at startup.
