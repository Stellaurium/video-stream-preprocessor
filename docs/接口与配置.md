# 预处理接口与配置格式

HTTP端点和两应用的坐标交接，以[模块协作接口](模块协作接口.md)为准。

## Pipeline接口

```python
from screenprep.geometry import Pipeline

pipeline = Pipeline.load("data/calibration.json")
result = pipeline.render(original_bgr_frame)
```

输入必须为`uint8 H×W×3 BGR`且分辨率与配置一致。几何类还提供crop、perspective、undo、redo、clone、set_render_options与save。不要只取矩阵忽略有效区域和采样设置。

## 标定JSON

schema为`screenprep.calibration`，当前version为3，兼容读取1/2。关键字段：

| 字段 | 含义 |
| --- | --- |
| `input_size` / `output_size` | `[width,height]` |
| `coordinate_system` | `pixel_centers_xy_top_left` |
| `operations` | 顺序操作，每步含输入/输出尺寸、矩阵及裁剪或四点参数 |
| `source_to_output` | 原始输入→最终输出的3×3单应矩阵 |
| `valid_output_polygon` | 最终画布中仍然有效的原始内容区域 |
| `rendering.interpolation` | `linear`、`cubic`、`lanczos4`，默认后者 |
| `rendering.sharpen_amount` | 0–0.6，默认0.2 |
| `lens_correction` | 当前必须为null，不支持径向镜头参数 |

透视操作的`points`是当前步骤的左上、右上、右下、左下；`reference_size`描述标定区域；`framing`是screen/margin/full，`margin_ratio`为每侧留边比例。裁剪`rect=[x,y,width,height]`采用半开范围。

载入时重建操作并校验尺寸连续性、范围与最终尺寸；不盲信文件里给出的复合矩阵。旧版本载入使用当前默认高质量采样，若需原双线性效果需手动设置linear和0锐化。

## Headless与SDK

在项目根目录及本项目环境运行：

```powershell
.\.venv\Scripts\python.exe -m screenprep.headless --source "camera:OBS Virtual Camera" --config data\calibration.json --port 8765
```

与GUI不要占用同一端口，也不要争抢独占输入。下游可用`screenprep.sdk.FrameClient`，使用示例见共享接口文档；本机NPY是无损序列化，跨机一般用PNG。不要把MJPEG有损预览的截图称为原始无损图。
