# 源码发布与本机数据

本仓库只保存运行源码、安装入口、固定资源、使用/接口文档和可重复的自动化回归测试。首次使用先安装 Windows x64 Python 3.11，再运行 `tools/安装依赖.cmd`。正常启动不需要重新安装依赖。

## 提交范围

- `.venv/`、`bin/`中的可执行文件、`data/`、题库、聊天SQLite、日志、用户标定和截图不提交。
- OCR模型权重由显式安装命令下载并按固定SHA256验证，不随Git提交。
- `tests/`只保留临时目录/合成图片/本机模拟HTTP的回归测试，不读取个人题库，不默认调用付费API。
- 一次性实验、真实题目验收、API探针和报告放在仓库外的测试目录，不能以备份源码的形式重新混入仓库。
- API Key只通过界面存入Windows凭据管理器，不写源码、README或配置示例。服务地址和模型名是可配置项。

## 本机数据

忽略规则让本机现有配置继续可用；它不是数据擦除工具。分享时使用Git提交或 `git archive`，不要直接压缩整个正在使用的项目目录。题目图片、OCR文字、答案和聊天记录都可能包含私人内容。

每次准备发布先运行 `git status --short` 和 `git diff --cached`，确认待提交列表不包含上述数据。不要使用 `git add -f`绕过忽略规则。

## 迁移与恢复

源码可重新clone/解压后执行setup。Windows虚拟环境不承诺可跨路径搬移，请在新位置重建。配置与题库按需单独迁移，API Key在新电脑重新输入。当前交付是源码setup方式，不包含打包EXE或免setup便携运行时。
